📖 Descripción: Calcula medidas de tendencia central, dispersión y posición para datos numéricos sin agrupar. Compara la varianza poblacional (divide entre n) con la varianza muestral (divide entre n-1).

📥 Datos de entrada

Escribe los números separados por comas, espacios o saltos de línea. También puedes importar un archivo de texto (.txt o .csv).

📂 Importar archivo:
El archivo debe contener números separados por comas, espacios o saltos de línea.

📋 Resultados

⚠️ Comparación de varianzas: La varianza POBLACIONAL (σ²) divide entre n y se usa cuando los datos representan toda la población. La varianza MUESTRAL (s²) divide entre n-1 y se usa cuando los datos son una muestra. La muestral es ligeramente mayor porque corrige el sesgo de estimación.
